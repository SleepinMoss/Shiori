# Shiori
A simple config manager. Actively in development. Pre-Alpha.

## How to use
First of all, add a directory of your config to backup (add category), then name it. That's it. If you want to backup your current setting just press the "+" button. To switch back to a config backup, just press the button. Don't worry it will automatically create a backup of current config if you forgot to make one before switching.
